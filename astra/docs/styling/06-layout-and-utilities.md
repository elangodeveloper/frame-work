# Layout System & Utility Classes

## 1. Responsive Grid & Flexbox Utilities
JARVIS includes a lightweight, zero-runtime utility set under @layer jarvis-utilities:
- **Flexbox**: .jarvis-flex, .jarvis-flex-col, .jarvis-items-center, .jarvis-justify-between, .jarvis-gap-2, .jarvis-gap-4.
- **CSS Grid**: .jarvis-grid, .jarvis-grid-cols-2, .jarvis-grid-cols-3, .jarvis-grid-cols-4.
- **Containers**: .jarvis-container with fluid responsive max-widths.

## 2. Atomic Helpers
- Spacing: .jarvis-m-0, .jarvis-p-2, .jarvis-p-4, .jarvis-mb-4.
- Display & Overflow: .jarvis-hidden, .jarvis-block, .jarvis-overflow-hidden.
- Typography: .jarvis-text-sm, .jarvis-text-center, .jarvis-font-bold.
